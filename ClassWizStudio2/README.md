# ClassWiz Studio Calculator 2.0 — Android

This folder contains the Android WebView project for ClassWiz Studio Calculator 2.0.

## Build an APK on GitHub
1. Open the repository's **Actions** tab.
2. Select **Build ClassWiz Studio 2.0 APK**.
3. Tap **Run workflow** and confirm.
4. When the run succeeds, open it and download the **ClassWiz-Studio-2.0-debug-APK** artifact.
5. Extract the downloaded ZIP and install the APK on your Android phone.

The workflow builds a debug APK for testing. A signed release build is needed for Play Store distribution.
